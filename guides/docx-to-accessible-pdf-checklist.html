DOCX to accessible PDF checklist: export is not enough

By Preflight A11y · 29 October 2026 · 6 minute read

“Save as PDF” does not make a document accessible. The PDF has its own structure: tags, reading order, alt text, table headers, bookmarks, and form labels. A clean Word file helps, but the export and the PDF itself still need checking.

Two-stage check: first preflight the DOCX, then check the PDF separately. Do not assume the export preserved the structure.

1. Fix the DOCX before export

  • Real heading styles, in order.
  • Document title and language set.
  • Alt text for meaningful images; decorative images marked.
  • Table header row and repeated header row.
  • Descriptive links.
  • No tracked changes or unresolved comments.

A DOCX preflight can catch several of these; it cannot verify whether alt text is meaningful.

2. Use the right export path

In Word, use File → Save As → PDF and look for the option to create a tagged PDF (wording varies by version). Do not print to PDF from a browser or a generic print dialog; that can drop tags and structure.

3. Check the PDF’s tags and reading order

  • Open the PDF in a tool that exposes tags (Acrobat, PAC, or an equivalent).
  • Confirm the document has a tag tree, not just page content.
  • Check the reading order of a multi-column page and a table.
  • Confirm headings are tagged as headings.
  • Confirm figures have alt text.

4. Check tables

Header cells should be tagged as table headers, with scope. Merged cells and nested tables can make the reading order ambiguous. If the table is complex, simplify it or provide an accessible alternative.

5. Check forms and links

  • Form fields have labels and a logical tab order.
  • Links have descriptive text and a visible focus state.
  • No empty or “click here” links.

6. Check scanned pages

If the PDF is a scan, it needs OCR and a tagged reading order. An image of text is not accessible text. A scanned syllabus with a clean visual layout can still be unusable with a screen reader.

7. Do a screen-reader spot check

Open the PDF with a screen reader and navigate by headings, links, and tables. Confirm the order and labels make sense. This is the step that catches “tagged but wrong” PDFs.
