    Structure

    Non-text content

    Interaction & data

    Ambiguous links, tables without header rows, tiny text, tracked changes, and comments.

    What it cannot do

    It cannot certify WCAG/ADA/EAA compliance, judge whether alt text is meaningful, test screen-reader pronunciation, or remediate the file. A manual review is still required. This is not legal advice.

    Questions

    Before you scan a real file

    Is this a compliance certificate?

    No. It is an automated preflight. It cannot establish WCAG, ADA, EAA, or Section 508 conformance, and it is not legal advice. A human still needs to review meaning, reading order, and screen-reader behaviour.

    Do you upload my document?

    No. The public static build parses the DOCX/PPTX in your browser with JSZip. There is no upload endpoint and no server-side storage. The separate local Python build can use a local Ollama model; it is not part of this static site.

    Does it support PDF?

    Not yet. This version covers DOCX and PPTX. PDF has different requirements (tags, reading order, bookmarks, form labels), so do not treat a DOCX preflight as a PDF audit.

    Can I use the report with a client?

    The report is generated locally and you can download it. It is a free research preview, provided as-is, without a warranty or a certification claim. If you need a manual review or a white-label agency report, use the pilot request link.

    Is the public version using AI?

    The public browser build uses a rules engine plus a template summary; it does not call a cloud LLM. The local Python build can generate an AI summary with a local Ollama model. No document text is sent to a third-party AI API in either build.

    How much does it cost?

    Nothing during the research pilot. Payment is not enabled. The planned test price, if the pilot proves useful, is $19 per report or $49 for five files; that is a hypothesis, not a validated price.
