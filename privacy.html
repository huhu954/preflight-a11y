Privacy & data handling

Your file never leaves your browser.

This is a static, browser-only research preview. There is no upload endpoint and no server-side storage. It is not a production service and it does not provide legal advice.

1. Files you scan

  • The DOCX/PPTX is read with JavaScript in this tab using the File API and JSZip.
  • It is not sent to this website, to GitHub, or to any third-party AI API.
  • No copy is stored in the browser after the tab is closed; the report exists only in memory until you download it.
  • Do not scan student records, identity documents, medical data, or material you do not have the right to process.

2. No AI API calls

  • This static build uses a rules engine, not a cloud LLM. The summary is generated from the detected findings.
  • The separate local Python build can use a local Ollama model; it is not part of this public static site.
  • No document text is sent to OpenAI, Google, Anthropic, or any other provider.

3. What is collected

  • No analytics, no cookies, no fingerprinting, no server logs.
  • GitHub Pages may process standard technical request data (IP address, user agent) to serve the page; that is governed by GitHub's privacy statement, not by this app.
  • If you open a GitHub issue, GitHub stores your public issue content. Do not put confidential documents or personal data in a public issue.

4. Retention

  • Files: not retained; processed in memory only.
  • Reports: not retained; downloaded to your device at your request.
  • No waitlist or email database exists in this static build.

5. Your rights

This static preview does not intentionally collect personal data. If you are in the EU/UK and believe a GitHub issue you opened contains personal data, you can edit or delete that issue in GitHub. For questions about the project, use the public GitHub repository.

6. Security

The app runs in your browser with no backend. File-size, ZIP-count and XML-entity checks reduce unsafe input. It has not been penetration-tested. Do not treat it as a confidential document portal.

7. What this report is not

It is an automated preflight, not a certification, audit opinion, or legal advice. It cannot establish WCAG, ADA, EAA, or Section 508 compliance. A qualified human must review the document and its context.

Last updated: 2026-10-29. This page is a plain-language notice for a research prototype, not a substitute for a lawyer-reviewed privacy policy.
